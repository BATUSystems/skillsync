6. „dashboard serve” w worktree, gdy serwer już działa

Karta sesji B uruchamia tę samą komendę co zawsze. Bez flag nasłuchu dopisuje zakładkę i wypisuje jej adres (z jej własnym tokenem), kod 0, bez nowych portów. Z flagą nasłuchu startuje osobny serwer jak dziś.
