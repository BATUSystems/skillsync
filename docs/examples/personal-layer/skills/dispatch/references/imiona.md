# Imiona kart

Dyspozytor nadaje kartom roboczym aliasy z tej listy. Podpis wiadomości karty ma postać `<Alias>/<paczka>`, np. `Ada/<paczka>`.

## Lista imion

| Imię | Rodzaj gramatyczny |
|---|---|
| Ada | żeński |
| Leon | męski |
| Iga | żeński |

## Zasady

- Imiona nadawane są w kolejności listy, od góry.
- Alias jest ASCII bez spacji i pasuje do wzorca `[A-Za-z0-9][A-Za-z0-9_.-]{0,79}`.
- Po wyczerpaniu listy kolejne karty dostają `<Imię>-2`.
- Alias nie wraca w obrębie jednego przebiegu.
- Nazwy nadane przez użytkownika mają pierwszeństwo przed listą.
